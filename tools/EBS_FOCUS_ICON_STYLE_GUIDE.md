# Hearts of Iron IV: EBS National Focus Icon Unified Artstyle & Strict Prompt Specification

> [!IMPORTANT]
> **设计宪章（Design Charter）**：  
> 本规范废除了此前缺乏宏观统御、零散拼凑的国策图标旧方案。  
> 确立**“国家统一宏观大风格（National Macro-Style） + 各分支专有微观小风格（Branch Sub-Style） + 提示词硬性不可更改锁定条令（Immutable Style Lock Clause）”**的三阶提示词架构，确保 EBS 全树 82 个国策图标既拥有强烈的国家整体辨识度与历史厚重感，又在不同政治派系路线下展现鲜明独特的视觉图腾。

## 第一部分：国家统一宏观大风格 (National Macro-Style Specification)

整个 EBS（教育部 / 最高教育巡视督导专员公署）作为一个具有 1930-1940 年代浓厚威权官僚、应试极权与黑色幽默色彩的政权，其所有国策图标必须严格共享以下**统一宏观大风格**：

### 1. 核心艺术载体与手绘质感
- **风格宗源**：严格遵循《钢铁雄心4》（Clausewitz Engine）官方水粉/复古宣传画（1930s-1940s vintage gouache & propaganda illustration）艺术规范。
- **笔触与材质**：厚重细腻的油彩与水粉颗粒质感，金属高光带有柔和手工打磨拉丝痕迹，杜绝现代矢量矢图的单薄感。

### 2. 国家宏观基底色彩矩阵 (National Macro Palette)
- **权威普鲁士深蓝 (`#15202B`)**：作为沉稳的阴影与官僚背景基底，象征中央行政机构的冷酷与秩序。
- **典雅古典黄铜金 (`#C5A059` ~ `#D4AF37`)**：用于所有图标的外围金属饰件、桂冠、齿轮与铭牌，提供统一的 UI 视觉锚点。
- **督导火漆朱砂红 (`#8B0000` ~ `#A81818`)**：用于官印、绶带、印章与核心警示，象征不可违抗的部令。
- **陈年档案米褐 (`#F4ECD8`)**：用于泛黄考卷、公文纸张与地图背景，体现历史年代质感。

### 3. 统一外围构图锚点 (Unified Heraldic Framing)
每个图标主体外围均需带有 HOI4 经典金属构件锚点（黄铜月桂叶、重型机械齿轮牙口、双向卷曲红金绶带、或带有倒角抛光的金属徽章托底），使得图标在游戏内国策树黑色背景与金色连接线中呈现完美的资产规整度。

### 4. 光影与画幅契约
- **光照**：45度左上方温暖戏剧性主光（暖黄色 Key Light），右下方带有微妙的深冷环境反光与轮廓边缘光（Rim Lighting）。
- **底板与格式**：纯透明背景（RGBA 32-bit Transparent），无任何矩形死板色块，轮廓边缘清晰平滑。

### 5. 绝对负向锁定（Strict Negative Prompts）
- 严禁任何现代扁平矢量极简图形（No flat vector minimalism）。
- 严禁任何现代 3D 塑料感渲染（No modern 3D CGI plastic render）。
- 严禁现实人物照片真人头直接贴图（No photo real human faces）。
- 严禁在画面中生成任何文字、汉字、字母、阿拉伯数字（No text, typography, letters, digits）。
